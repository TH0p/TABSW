# Single Tab Switcher para Zen Browser (Sine Mod)

Substitui o atalho `Ctrl + Tab` por apenas `Tab` para alternar entre as abas abertas no Zen Browser.

- **Tab**: Avança para a próxima aba.
- **Shift + Tab**: Retorna para a aba anterior.
- **Campos de Texto**: Quando o cursor estiver na barra de endereços ou em caixas de texto de páginas, a tecla Tab funcionará normalmente para navegação/digitação.
